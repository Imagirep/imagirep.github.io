# ImagiRep project page

Static project page for *Representing the Unseen: Rethinking Visual Imagination for Spatial Reasoning*.
Plain HTML/CSS/JS, no build server; `index.html` is generated and committed so GitHub Pages can serve it as is.

## Layout

| Path | What it is |
|---|---|
| `index.src.html` | Page source (edit this, not `index.html`) |
| `partials/teaser.html` | Animated teaser, generated by `tools/build_teaser.py` |
| `static/css/style.css` | Styles, light and dark tokens |
| `static/js/` | `teaser.js` (teaser timeline), `charts.js` (result charts), `explorer.js` (benchmark examples), `main.js` (page glue) |
| `static/data/` | `results.json` (paper numbers), `examples.json` (explorer questions) |
| `static/teaser/`, `static/video/`, `static/img/`, `static/fig/` | Teaser layers, scene and example videos, example images, paper figures |
| `tools/` | Build and asset scripts (not needed to serve the page) |

## Build

```bash
TEASER_PPTX=path/to/teaser.pptx python tools/build_teaser.py   # only when the teaser layout changes
python tools/build_site.py     # inlines teaser + data into index.html, adds cache-busting ?v= hashes
```

Preview locally with `python -m http.server 8765` and open http://127.0.0.1:8765/.

## Deploy (GitHub Pages, personal account)

1. Create a public repository under the personal account (for example `imagirep`).
2. Push this folder to its `main` branch.
3. Settings -> Pages -> Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
4. The page appears at `https://<user>.github.io/<repo>/`. `.nojekyll` keeps GitHub from running Jekyll.
5. After the first deploy, change `og:image` in `index.src.html` to the absolute URL
   (`https://<user>.github.io/<repo>/static/fig/og.jpg`) and rebuild, so link previews show the teaser.
